# Adaptive reading stories

Planning docs for TutorLumi's reading-stories feature for dyslexic students. No app code yet.

| File | What it is |
| --- | --- |
| [`spec.md`](./spec.md) | The feature spec: levels, placement test, weekly story cycle, review, read-aloud, feedback, progress view |
| [`sample-story.json`](./sample-story.json) | One Level 2 fiction story with questions, answer key and tags, in a shape the app could load |
| [`mockup/index.html`](./mockup/index.html) | Clickable mockup of reading that story: read, answer the questions, rate it. Open it in a browser. |

The mockup makes no sound. Its word highlighting runs on a timer to show the behavior; the real app will play pre-generated Azure audio with word timings.
